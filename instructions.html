Marks table instructions

Theory Marks and Lab Marks · for the admin

In short: add columns with + Add column (at the end or at any place), type marks or AB, and make calculated columns with a formula such as =ROUNDUP(SUM(C5:H5)*20/230,0). Lab Marks also has a description for every column and colors that the admin sets for each row and column.

1. Entering marks

  • ✎ on a column (in the column heading): type or change that one column for all students in a list. Fill all puts the same mark for everyone, Clear all empties the column.
  • Edit on a row: type the marks of one student for all columns.
  • ⚙ on a column: rename, change type, set the maximum marks, change the description (Lab Marks), or delete the column.

2. Adding a column at any place

  • Click + Add column. In Where to add this column choose At the end (the default), At the very beginning, or Before any column. This works in both Theory Marks and Lab Marks.
  • The list Column letters in the window shows the letters the columns will have after your new column is added. Use those letters when you type the formula of the new column.
  • The marks already entered are never moved or lost; the new column is simply empty.
  • Formulas move with the columns (like Excel): when you add a column in the middle, the column letters inside the other formulas are updated for you. Example: =SUM(C5:E5) becomes =SUM(C5:F5) when a column is added before D or E, stays the same when it is added before F (after the range), and =SUM(D5:F5) when it is added at the very beginning. Formulas that use [Names] never change.
  • A column added inside a range joins that range. If the total is =SUM(C5:E5) and you add a column between C and E, the new column is counted in the total too. If you do not want that, add the column before the first or after the last column of the range, or write the total with names: =SUM([Lab 1],[Lab 2],[Lab 3]).
  • Moving or reordering an existing column is not possible: add the column where you want it, copy the marks, and delete the old one.

3. AB (absent)

  • Type AB (or ab) instead of a number for an absent student. It is shown as AB in the table, in PDF, Word and Excel.
  • Formulas ignore an AB cell in that student's row, like an empty cell: SUM and AVERAGE skip it, and in + - * / it counts as 0.
  • Example: Lab 1 = AB, Lab 2 = 10, Lab 3 = 20 → =SUM(C5:E5) gives 30 and =AVERAGE([Lab 1],[Lab 2],[Lab 3]) gives 15.
  • If a student is AB in every marks column, the formula columns show 0 (or blank for AVERAGE).

4. Column letters

Letters are shown above the table: A Reg No, B Name, C first column, D second column, and so on. The row number is ignored: C5:H5 simply means "columns C to H of each student's own row". $ signs ($C$5) are allowed and ignored.

Adding a column in the middle updates the letters in the other formulas automatically (section 2). Deleting a column does not: the letters of the columns after it move one place left, so check formulas that use letters (like C5:H5). Formulas that use names in brackets follow the column automatically.

5. Writing a formula

Choose Column type → Formula and type it like Excel. A formula starts with = (maximum 300 characters). A formula column is calculated for every student and cannot be typed into. You can refer to other columns in three ways:

7. Maximum marks of a column

  • In ⚙ on a marks column, type Maximum marks (for example 25). A mark above it is refused. The heading shows /25.
  • Formulas can read it with OUTOF([Column name]).
  • Example, Lab 1 and Lab 2 are both out of 25 and the total is needed out of 15:
    =SUM([Lab 1],[Lab 2])*15/(OUTOF([Lab 1])+OUTOF([Lab 2]))
  • In Quick build, choose SUM, tick the columns and fill Scale to (15 here): this formula is typed for you.

8. Theory Marks: AAT 1

AAT 1 is built in and mandatory (🔒). It cannot be renamed, changed or deleted, but you can set its maximum marks. All other columns are created by the admin.

9. Description of a column (Lab Marks)

In the column window (⚙ or + Add column) you can type a short Description of this column (up to 200 characters, for example Record work of experiments 1 to 5). It is shown under the column name in the table for everybody who can see the marks. Leave it empty to show nothing.

10. Colors (Lab Marks)

In Lab Marks nothing is colored by itself. There are two kinds of colors:

  • Row colors (by hand) – tap the round swatch at the start of a row (next to the Reg No) and pick a color, or use 🎨 Row colors to set every row in one list (Set all rows, ✕, Clear all).
  • Column colors (by condition) – press 🎨 Column colors (or the 🎨 in a column heading), choose the column and add rules. Each rule is a condition and a color, for example is less than 11 = red, is less than 16 = blue, is greater than or equal to 16 = green. The conditions are: less than, less than or equal, greater than, greater than or equal, equal to, between (both numbers included), is AB, and every cell. Quick: red / blue / green fills this example for you. Copy these rules to all columns uses the same rules for every column.

🎨 Row conditions – colors the whole row by the value of ONE column. Choose The WHOLE ROW in the list, choose the deciding column (for example Total) and add rules as above. A color you set by hand on a row wins over the row conditions.

Order matters: a cell is checked against the rules from the top to the bottom and gets the color of the first rule that fits. So put the smaller limits first (11, then 16). A cell that fits no rule stays uncolored. The rules also work on formula columns such as Total, and are checked on the value shown in the table.

Where a row color and a column rule meet, the rule color shows. A small legend under the table tells everybody what each color means. The colors are saved for that subject's Lab Marks sheet, so every viewer (CR, and the student on his / her own row) sees the same colors.

11. Download

Excel keeps the formulas, PDF and Word get the calculated values and the row colors and the column rule colors (Excel has no colors). An AB cell is written as AB. The Excel formulas treat AB like the website does: it counts as 0 when you add, subtract or compare, and SUM, AVERAGE, MAX, MIN skip it.

12. Who sees what

The admin sees every student and can change marks. A CR sees every student's marks of the assigned subject, view only. A student sees only his / her own row. When you press Publish, the students get one e-mail saying the marks are published (the e-mail never contains marks).

14. Lab batches (Lab Programs only)

In a Theory + Lab subject the admin splits the students into Batch 1 and Batch 2:

  • Lab Programs → Create batches (first step). Type or paste the Reg Nos of each batch and press Apply the typed Reg Nos, or choose the batch of every student in the list. Split in half puts the first half of the list in Batch 1 and the rest in Batch 2. Each batch has its own color. A student is in only one batch.
  • Posting a lab program: first choose the batch, then the lab number, date, time, lab location, title, Drive link or code and what to do. Only the students of that batch see the program and only they get the e-mail. Choose Both batches to post the same program for Batch 1 and Batch 2 at once; one e-mail goes to the students of both batches. Programs posted before batches were created stay visible to everybody.

15. Import marks and Publish

  • ⬆ Import: paste from Excel (or choose an .xlsx / .xls / .csv file). Row 1 = headings; one heading must be Reg No, the other headings are column names. Press Check, read the summary, then Import. Name and formula columns are skipped, an empty cell keeps the old mark, AB is accepted, and a mark above the column maximum stops the import.
  • Publish to students: a new sheet is hidden from the students (and the CR) until you publish it; they get a bell notification. Unpublish hides it again. You always see everything.

16. Timetable

  • Menu → Timetable. Choose the Year and Semester, press Create timetable. Rows = Monday to Saturday, columns = 9 periods (9.00 to 9.50 ... 3.40 to 4.30).
  • Tap a cell: type the text (or choose a subject), choose the type (Theory, Lab, Break, Other) and Merge: periods covered. A lab of 9.00 to 11.30 = 3 periods merged. Choose 1 again to split it.
  • ⚙ next to a day: copy the whole day from another day, or clear it. ⏱ Edit times changes the period times. Excel keeps the merged cells; Print / PDF prints the page.
  • A student sees the timetable of his / her own Year and Semester; the CR can open any timetable.

13. If a formula shows Err or is refused

  • Err in the table: the formula cannot be calculated for that student. Common reasons: dividing by zero, a [Name] that no longer exists (the column was renamed or deleted), a letter that no longer points to the column you meant (after deleting a column), or a formula that uses its own column.
  • "The formula is not valid": check the brackets ( ) and [ ], the commas between values, the quotes around text, and that every function name is spelled correctly.
  • A blank formula cell: no mark is entered yet in that student's row.
  • Column names cannot contain [ or ] and must be different from each other.
